# Roller Coaster TensorFlow Project

This project demonstrates basic data analysis and TensorFlow preprocessing using a roller coaster dataset.

## Features
- Data analysis using Pandas
- Data visualization using Matplotlib
- Missing value handling
- Tensor conversion with TensorFlow
- Feature engineering
- Tensor reshaping

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- TensorFlow

## Dataset
The dataset used is:

```text
coaster_db.csv
```

## How to Run

Install required libraries:

```bash
pip install pandas numpy matplotlib tensorflow
```

Open and run:

```text
project.ipynb
```

using:
- VS Code
- Jupyter Notebook
- Google Colab
